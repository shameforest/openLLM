# openLLM

Ein kostenloser, lokaler KI-Programmierassistent wie Claude Code — läuft mit offenen Modellen auf dem eigenen PC, ohne Abo und ohne fremde Programmierschnittstelle (*API*). Arbeitsname, kann noch umbenannt werden.

**Stand:** Recherche und Plan sind fertig (Meilenstein M0). Als Nächstes das Fundament (M1): Modell-Server, ein Modell und die Agenten-Hülle laufen zusammen.

- [Plan und Architektur](docs/PLAN.md)
- [Recherche: Modelle, Hülle, Server](docs/RESEARCH.md)
- Schwesterprojekt: **OpenDali** (lokaler Bildgenerator), im Repo `shameforest/ai`.

> Ehrliche Erwartung: Auf einer 24-GB-Grafikkarte wird dies ein brauchbarer Assistent für klar umrissene Aufgaben, bleibt aber bei langen, selbstständigen Läufen unter dem Niveau von Claude Code (Konfidenz 75).
